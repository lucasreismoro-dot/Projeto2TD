# Biblioteca Escolar Online – Projeto de Feira Cultural

## 📝 Descrição do Projeto
Este projeto é um **sistema de biblioteca online** para a escola, feito com **HTML, CSS e JavaScript**.  
Ele permite:

- Cadastrar livros e alunos.  
- Listar livros disponíveis e alunos cadastrados.  
- Registrar empréstimos e controlar a disponibilidade dos livros.  

O projeto envolve **programação front-end**, **estrutura de dados (JSON/LocalStorage)** e **planejamento de sistema**, incluindo análise de entidades e funcionalidades.

## 🚀 Passo a Passo para Começar

### 1️⃣ Clonar o Projeto
1. Faça o download ou clone este repositório.  
2. Abra a pasta do projeto no seu editor de código (VS Code, Sublime, etc.).  

### 2️⃣ Abrir no Navegador
1. Abra o arquivo `index.html` no navegador.  
2. Você verá a tela inicial com o menu: Home, Livros, Alunos, Empréstimos.  
3. Navegue entre as páginas usando os botões do menu.  

### 3️⃣ Conhecer o Código
- `index.html` → estrutura das páginas e formulários.  
- `style.css` → cores, layout e estilo geral do site.  
- `script.js` → todas as funções de cadastro, listagem e empréstimos.  

> Dica: Comece entendendo o `showPage()` no `script.js` que controla a navegação entre páginas.

## ⚙️ Checkpoints do Projeto

### **Checkpoint 1 – Navegação**
- Testar se os botões do menu mostram as páginas corretas.  
- Funciona sem nenhum cadastro ainda.  

### **Checkpoint 2 – Lista de Livros**
- O sistema já vem com alguns livros cadastrados.  
- Eles aparecem na seção "Livros".  

### **Checkpoint 3 – Cadastro de Livros**
- Preencher o formulário de livro (Título e Autor) e clicar em Adicionar.  
- O livro deve aparecer na lista.  

### **Checkpoint 4 – Cadastro de Alunos**
- Criar lista de alunos similar à lista de livros.  
- Formulário para adicionar novos alunos.  

### **Checkpoint 5 – Empréstimos**
- Formulário para registrar empréstimos (aluno + livro).  
- Atualizar a disponibilidade do livro.  
- Listar todos os empréstimos realizados.  

### **Checkpoint 6 – Estilização e Extras**
- Melhorar o CSS (cores, fontes, layout).  
- Adicionar filtros (ex: livros disponíveis).  
- Validar formulários e mostrar mensagens de sucesso ou erro.
